# DAYBREAK — The New Year Edition 🌅

> **Make it before sunrise.**  
> A 24-hour teen hackathon in Bengaluru, India organised by [ShipIt Teens](https://ship-it-teen.vercel.app/).  
> December 31, 2026 – January 1, 2027

---

## ⚡ Overview

**DAYBREAK** is about spending the transition into a new year building something meaningful instead of simply counting down to midnight. Over 24 continuous hours, 150+ teen developers, designers, hardware hackers, and creative technologists gather in Bengaluru to turn ideas into running code, hardware prototypes, and digital art before the first sunrise of the new year.

---

## 📺 DAWIN — The Official Mascot

**DAWIN** is a retro CRT television monitor companion with an expressive phosphor screen face, dual aerial antennas, and a sunrise motif. Integrated throughout the site:
- Interactive facial mood changer (`HAPPY`, `HACKING`, `SUNRISE ZEN`, `MIDNIGHT 00:00`, `NEED COFFEE`, `BLOWN AWAY`)
- Synthesized 8-bit web audio sound effects on user interaction
- Overnight hardware survival arsenal

## 🚀 Key Sections

1. **Navigation:** Brand logo with sunrise emblem, subtle ShipIt Teens parent badge, live countdown, 8-bit SFX toggle, and mobile menu.
2. **Hero:** Monumental DAYBREAK typography, sunrise radial illustration, Bengaluru skyline (featuring Vidhana Soudha dome), live countdown clock, and interactive DAWIN mascot companion.
3. **The Manifesto:** "A new year. A new build." — Side-by-side editorial comparison contrasting passive countdown parties with the Daybreak builder flow.
4. **The Experience:** 4 chapters: *Build Through The Night*, *Find Your People*, *Experiment Without Limits*, *Demo Day At Sunrise*.
5. **Tracks:** *Open Projects*, *Hardware Hacks*, and *Demo Day & Celebration* with interactive starter prompt inspector.
6. **Schedule:** 24-hour visual timeline with phase filtering (Kickoff, Midnight Shift, Night Owl, Sunrise Sprint).
7. **Interactive Attendee Badge Generator (v1.0):** Directly modeled after the official Event Design Sheet badge with customizable hacker name, handle, track, and flippable front/back lanyard views.
8. **Sticker Pack & Merch Showcase:** Tactile stickers and swag collection.
9. **FAQ:** Smooth accordion answering all eligibility, safety, and logistical questions.
10. **Final CTA:** "DON'T JUST COUNT DOWN. BUILD SOMETHING." with celebratory confetti cannon.
11. **Registration Modal:** Solo or squad registration dialog with instant feedback.

## 🛠️ Tech Stack

- **Framework:** React 18 + TypeScript
- **Styling:** Tailwind CSS + PostCSS
- **Icons:** Lucide React
- **Animations & Effects:** Custom CSS keyframes, Canvas Confetti, Web Audio API sound synthesizer
- **Bundler:** Vite 6

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Ares006-007/daybreak-bengaluru.git
cd daybreak-bengaluru

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
